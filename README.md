# Clon de Interfaz de Apple - API REST

Este proyecto es una clonación de la interfaz visual de **Apple**, desarrollada como parte del Trabajo Práctico Grupal N° 2[cite: 1].

## Descripción
La aplicación recrea la maquetación elegante y minimalista de Apple, consumiendo en tiempo real datos desde una API REST pública (Fake Store API) para alimentar la sección de catálogo[cite: 1].

## Características
- **Maquetación:** Flexbox y CSS Grid.
- **Responsividad:** Soporte optimizado para 4 tamaños de pantalla (`1080px`, `768px`, `480px`, `375px`)[cite: 2].
- **API REST:** Carga dinámica de productos vía `fetch` en JavaScript[cite: 1].
- **Imágenes:** Las miniaturas actuales del catálogo se guardan en `img/products/` y se cargan localmente.
- **Fuente local:** Inter (pesos 300, 400, 500 y 600) se carga desde `assets/fonts/`. Incluye su licencia SIL Open Font License.
