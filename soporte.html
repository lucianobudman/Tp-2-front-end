Preguntas frecuentes

Consultas habituales

¿Cómo puedo realizar una compra?

Ingresá a Comprar, elegí un producto y utilizá el botón para agregarlo a tu bolsa.

¿La compra realizada tiene cobro real?

No. El sitio es una demostración y ningún pedido genera un cobro ni una entrega real.

¿Puedo cambiar o devolver un producto?

Para una compra real debés consultar las políticas de devolución del vendedor correspondiente. Este proyecto no procesa devoluciones reales.

¿Cómo obtengo ayuda para mi dispositivo?

Podés completar el formulario de contacto indicando el dispositivo y el problema que estás teniendo.

¿Qué información necesito para solicitar soporte?

Incluí el modelo del dispositivo, la versión del sistema, una descripción del problema y los pasos que ya probaste.
